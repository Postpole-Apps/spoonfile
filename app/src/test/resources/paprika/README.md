# Recipe-file test archives

The `.paprikarecipes` files in this folder were generated for this project's tests. Their recipe text was
written by the Spoonfile authors and is released under CC0 1.0 (public domain dedication).

No files from Mealie, Tandoor or any other project are included here.

- `weeknight-basics.paprikarecipes`: two recipes, flat layout, with times, ratings, categories and numbered directions.
- `nested-with-debris.paprikarecipes`: one recipe inside a folder, plus `__MACOSX/` and `.DS_Store` entries that must be skipped.
- `mixed-quality.paprikarecipes`: one valid recipe (free-text time, bad photo data), one non-gzip entry and one entry without a name.
